# RRB JE + CUET Prep Tracker (Plain HTML/CSS/JS)

No install, no build tools, no npm, no git needed to just use it.
Everything is saved in your browser (localStorage).

## Try it right now

Just double-click `index.html`. It opens in your browser and works immediately.

## Put it online (GitHub Pages, no commands needed)

1. Create a new repository on GitHub (or open your existing one).
2. Click **Add file → Upload files**.
3. Drag in these 3 files: `index.html`, `style.css`, `app.js` (and `README.md` if you like).
4. Scroll down, click **Commit changes**.
5. Go to **Settings → Pages**. Under "Build and deployment → Source", choose
   **Deploy from a branch**, then pick branch `main` and folder `/ (root)`. Save.
6. Wait a minute, then your site will be live at:
   `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`
   (the link also appears on that same Settings → Pages screen once it's ready)

That's it — no Actions, no build step, no terminal commands required.

## Backing up your data

Everything lives only in your browser. Go to the **Settings** tab in the app:

- **Export full backup (JSON)** — keep this file safe (email it to yourself, save to
  Google Drive, etc.)
- **Import backup** — restores from a previously exported file (replaces current data)
- **Export sessions (CSV)** — spreadsheet-friendly export of just your study log

## Files

- `index.html` — page structure
- `style.css` — all styling (dark "control room" theme)
- `app.js` — all the logic (data storage, all 8 sections)
